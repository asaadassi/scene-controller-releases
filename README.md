# مدير المشاهد · Scene Controller

Signed Android releases of Scene Controller (مدير المشاهد), the Shihab App phone app that controls OBS Studio through its built-in WebSocket server. No source code here.

Each release: `SceneController-android-<version>.apk`, its publisher signature `.sig`, and `SHA256SUMS.txt`. The app checks this repository for updates.
